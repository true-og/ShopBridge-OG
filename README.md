# ShopBridge-OG

Compatibility plugin for
[QuickShop-OG](https://git.trueog.net/trueog/QuickShop-OG) or
[QuickShop-OG-Alt](https://git.trueog.net/trueog/QuickShop-OG-Alt) to support
[AreaShop-OG](https://git.trueog.net/trueog/AreaShop-OG).

ShopBridge-OG requires the exact Bukkit plugin name `QuickShop-OG`. It does not
support plugins named `QuickShop-Hikari`, `QuickShop-ReRemake`, or other
QuickShop forks.
