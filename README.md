# ShopBridge-OG

Compatibility plugin for
[QuickShop-OG](https://github.com/true-og/QuickShop-OG) or
[QuickShop-OG-Alt](https://github.com/NotAlexNoyle/QuickShop-OG-Alt) to support
[AreaShop-OG](https://github.com/true-og/AreaShop-OG).

ShopBridge-OG requires the exact Bukkit plugin name `QuickShop-OG`. It does not
support plugins named `QuickShop-Hikari`, `QuickShop-ReRemake`, or other
QuickShop forks.
